# 花舞之街 · 网站源码

网站实际用的是仓库根目录下压缩过的文件；这里（`_src/`）是带注释的源码。
GitHub Pages 不会发布以下划线开头的文件夹，所以访客打开网站时看不到这些源码。

## 文件分工

| 文件 | 内容 |
| --- | --- |
| `config.js` | 网站内容：最新活动、往期活动、小型回顾、花街介绍图、日历标注、卡片底图地址。**平时改内容只改它** |
| `index.html` | 页面结构（开屏图、首页、各个视图、弹窗），开头的脚本负责加载顺序、动画档位和开屏 |
| `style.css` | 全部样式，开头有目录 |
| `main.js` | 页面主程序：路由、首页与活动详情、特效、时间条与天气、点赞、闹铃、弹窗公告、花语弹窗、离线缓存 |
| `ticket.js` | 访客购票页与购票须知 |
| `venue.js` | 场地使用登记表单 |
| `survey.js` | 活动问卷 |
| `verify.js` | 人机验证（Cloudflare Turnstile + 狒科生 / 文科生 / 理科生） |
| `admin.js` | 内部入口与管理页（含管理面板的页面结构），进入 `#internal` 时才加载 |
| `huayu.js` | 花语入口：版本登记、自动识别一代 / 二代、和 Worker 之间的来回（「听得花间语」和管理页「花语加密」共用，打开时才加载） |
| `huayu/` | 花语的各个模块，生成发布版时和 `huayu.js` 拼成一个文件，见下面「花语」一节；`node huayu/selftest.mjs` 自测 |
| `sw.js` | 离线缓存（Service Worker）：看过的页面、脚本、图片存在访客本机，下次打开直接读 |
| `build.mjs` | 生成发布版 |
| `tools/make-thumbs.py` | 生成缩小版图片 `resized/…` 和竖屏天空 `assets/site/sky-*-p.webp` |
| `tools/make-brush-font.py` | 重新生成标题用的毛笔字 `assets/site/brush.woff2` |

脚本加载顺序：verify.js → config.js → main.js → ticket.js → venue.js → survey.js（admin.js、huayu.js 按需加载），
后面的文件会用到前面定义的函数和常量。

后端是 Cloudflare Worker（`worker.js`，不放在这个仓库里，改完在 Cloudflare 控制台粘贴部署），
挂在本站域名的 `/api/*`，数据在 D1，公告配图在 R2。

## 花语

右上角「更多」里的花朵按钮「听得花间语」：把一段话写成花语，或者把花语还原成原文。花语有两代：

- **一代（V1）**：「听花语：」+ 一串草木字，最短（中文大约一字换一字多一点）。以后一直保留，购票截图等需要短密文的地方用它。
- **二代（V2）**：写成一段像散文的句子（「菖蒲只在秋日开口，一开口就是声音最饱满的故事。」），长度约是一代的四五倍。

写花语用管理页「花语加密」里选定的那一代；听花语时自动认出是哪一代（先试二代句式，再试一代花字），两代都能解。

| 模块 | 内容 |
| --- | --- |
| `huayu/util.js` | 公用小工具：比特、base64、大数 |
| `huayu/zi.js` + `zi-data.json` | 字模型压缩：逐字预测 + 算术编码，中文平均每字 8 比特上下。一代的压缩器，也是二代的压缩方式之一 |
| `huayu/v1.js` | 一代：比特 ⇄ 539 个简繁同形的草木字（经过繁简转换也能解开） |
| `huayu/v2-lexicon.js` | 二代的词库（花名、景物、心绪、动作、样子、时候、地方……）和 48 个句式（展开后 98 个） |
| `huayu/v2-compress.js` | 二代的压缩：按不压缩 → DEFLATE → 字模型的顺序各试一遍，解回来核对无误的里面挑最短的 |
| `huayu/v2-sentence.js` | 二代的组句：比特串按「混合进制」取出句式号和词号，拼成句子；读回时去空白、换全角标点、繁体换简体后逐句对句式 |
| `huayu/v2.js` | 二代的头部（密钥类型、压缩方式）和打包 |
| `huayu/selftest.mjs` | 自测（Node.js 18+，在 `_src` 目录运行 `node huayu/selftest.mjs`） |

- Worker 负责加密（接口 `huayu_seal` / `huayu_open`，参数 `v` 指明第几代），密钥只存在 D1 的 `huayu_settings` 表里，
  网页拿不到；两代用不同的密钥派生，互不相通。网站不保存任何明文和花语。
- 长度：访客一次最多写 5000 字，管理员 20000 字；Worker 收的压缩后数据访客写最多 32KB，
  管理员写、任何人听最多 128KB（网页上写得出来的花语，一定听得了）。
- 管理页「花语加密」：访客端开关（完全开放 / 仅开放解密 / 彻底关闭，默认仅开放解密）、加密算法（一代 / 二代，默认二代）、
  站点密钥（换了以后保留最近 5 个旧密钥，以前的花语仍能解开），以及不受开关限制的完整转换
  （可选一代 / 二代、站点密钥 / 自定义密钥；访客听自定义密钥写的花语要自己填密钥）。
- 花语的弹窗和管理页「花语加密」所在的弹窗只能点右上角的 × 关（带 `data-close-only-x`，点遮罩、按 Esc 都不关）。
- **`zi.js`、`zi-data.json`、`v1.js`、`v2-*.js` 里的算法、参数、词库、句式决定了花语的写法，改动后以前写的花语会解不开，平时不要动。**
  要改只能另开新的一代，在 `huayu.js` 的 `ALGOS` 里登记，旧的几代原样保留。

## 加载与开屏

- 新访客先看到开屏莫古力；样式表和脚本随后下载。等待点击和旋转的这段时间里，
  天空、标题字体、花街介绍的底图先下载并解码好，接着是首页六张卡片底图，进站时直接显示。
- 点击后快速转两圈；进站要用的东西还没齐就一圈一圈接着转，齐了转完手上这一圈再进站。
- 进站后空闲时再加载谷歌字体、访问统计，注册离线缓存，并悄悄预取最新活动的海报和相册前几张缩略图。
- 手机竖屏用裁窄的天空图；手机上不预先下载另一套昼夜底图，点切换按钮时现取（图标会呼吸闪烁）。

## 动画档位

右上角动画按钮在三档之间切换：完整（飘落花叶 / 星光、悬停设计图等全部特效）→ 轻量（只保留点击、翻页时的短动画）→ 关闭。
默认：电脑完整，手机轻量，系统开了"减弱动态效果"时关闭；访客选过以后记在本机。

## 图片

- 页面上显示的是 `resized/720/…`（缩略图）和 `resized/1280/…`（大图）里的缩小版，点开大图时看原图；原图保持不动。
- **加了新图片（新活动的海报、封面、相册等）后**，在 `_src` 目录跑一次（需要 Python 和 Pillow）：
  ```
  pip install pillow
  python tools/make-thumbs.py
  ```
  再把生成的 `resized` 文件夹里新出现的图片一起上传。没跑也不会坏：缩小版不存在时网站自动退回原图，只是慢一些。
- 换了同名图片时，config.js 里那张图的地址后面加 / 改 `?v=数字`（缩小版也会跟着刷新），再跑一次上面的命令。

## 修改网站的步骤

1. 改 `_src/` 里的文件。
2. 发布新版本时，把 `_src/index.html` 里所有的 `20260930d` 换成新的日期（开头的 `HJ_VERSION` 一处 + 底部 `?v=` 几处），
   访客就会拿到新文件（离线缓存也会跟着更新）。
3. 生成发布版（需要 Node.js 18+）：
   ```
   cd _src
   npm install esbuild      # 只需第一次
   node build.mjs
   ```
   会覆盖根目录下的 index.html、style.css、sw.js 和各个 .js。
   同时生成 `activity/index.html`、`previous/index.html`：独立入口 /activity/（最新活动）和 /previous/（往期列表），
   和首页是同一个页面，直接显示对应内容、没有「← 返回」，地址栏不会跳成 /#latest、/#previous。带 # 的页面一律有「← 返回」。
4. 把 `_src/` 和根目录下变了的文件一起上传到 GitHub。

新活动名等标题里出现了新汉字时，可以跑一次 `python tools/make-brush-font.py` 更新毛笔字；
不跑也不影响使用，新字会用 Google 字体或系统字体显示。

万一离线缓存出了问题需要停用：按 `sw.js` 开头注释里的写法，把根目录的 `sw.js` 换成那几行上传即可。
