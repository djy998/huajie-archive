# 花舞之街 · 网站源码

网站实际用的是仓库根目录下压缩过的文件；这里（`_src/`）是带注释的源码。
GitHub Pages 不会发布以下划线开头的文件夹，所以访客打开网站时看不到这些源码。

## 文件分工

| 文件 | 内容 |
| --- | --- |
| `config.js` | 网站内容：最新活动、往期活动、小型回顾、花街介绍图、日历标注、卡片底图地址。**平时改内容只改它** |
| `index.html` | 页面结构（开屏图、首页、各个视图、弹窗），开头的脚本负责加载顺序、动画档位和开屏 |
| `style.css` | 全部样式，开头有目录 |
| `main.js` | 页面主程序：路由、首页与活动详情、特效、时间条与天气、点赞、闹铃、弹窗公告、花语弹窗、离线缓存 |
| `ticket.js` | 访客购票页与购票须知 |
| `venue.js` | 场地使用登记表单 |
| `survey.js` | 活动问卷 |
| `verify.js` | 人机验证（Cloudflare Turnstile + 狒科生 / 文科生 / 理科生） |
| `admin.js` | 内部入口与管理页（含管理面板的页面结构），进入 `#internal` 时才加载 |
| `huayu.js` | 花语的压缩与换字（「听得花间语」和管理页「花语加密」共用），打开它们时才加载 |
| `huayu-data.json` | 花语用的数据：字频、常见前后字搭配、花字表。生成发布版时填进 `huayu.js` |
| `sw.js` | 离线缓存（Service Worker）：看过的页面、脚本、图片存在访客本机，下次打开直接读 |
| `build.mjs` | 生成发布版 |
| `tools/make-thumbs.py` | 生成缩小版图片 `resized/…` 和竖屏天空 `assets/site/sky-*-p.webp` |
| `tools/make-brush-font.py` | 重新生成标题用的毛笔字 `assets/site/brush.woff2` |

脚本加载顺序：verify.js → config.js → main.js → ticket.js → venue.js → survey.js（admin.js、huayu.js 按需加载），
后面的文件会用到前面定义的函数和常量。

后端是 Cloudflare Worker（`worker.js`，不放在这个仓库里，改完在 Cloudflare 控制台粘贴部署），
挂在本站域名的 `/api/*`，数据在 D1，公告配图在 R2。

## 花语

右上角「更多」里的花朵按钮「听得花间语」：把一段话变成「花曰：」开头的一串草木字，或者反过来。

- 网页（`huayu.js`）负责压缩和换字：逐字预测 + 算术编码，中文平均每字 8 比特上下，所以花语通常和原文差不多长；
  花字只用简繁写法相同的字，经过繁简转换、夹进空格换行也能解开。
- Worker 负责加密（接口 `huayu_seal` / `huayu_open`），密钥只存在 D1 的 `huayu_settings` 表里，网页拿不到；
  网站不保存任何明文和花语。
- 管理页「花语加密」：访客端开关（完全开放 / 仅开放解密 / 彻底关闭，默认仅开放解密）、站点密钥（换了以后保留最近 5 个旧密钥，
  以前的花语仍能解开），以及不受开关限制的完整转换；转换时可以用自定义密钥，访客听这种花语要自己填密钥。
- **`huayu-data.json` 和 `huayu.js` 里的算法、参数决定了花语的写法，改动后以前写的花语会解不开，平时不要动。**

## 加载与开屏

- 新访客先看到开屏莫古力；样式表和脚本随后下载。等待点击和旋转的这段时间里，
  天空、标题字体、花街介绍的底图先下载并解码好，接着是首页六张卡片底图，进站时直接显示。
- 点击后快速转两圈；进站要用的东西还没齐就一圈一圈接着转，齐了转完手上这一圈再进站。
- 进站后空闲时再加载谷歌字体、访问统计，注册离线缓存，并悄悄预取最新活动的海报和相册前几张缩略图。
- 手机竖屏用裁窄的天空图；手机上不预先下载另一套昼夜底图，点切换按钮时现取（图标会呼吸闪烁）。

## 动画档位

右上角动画按钮在三档之间切换：完整（飘落花叶 / 星光、悬停设计图等全部特效）→ 轻量（只保留点击、翻页时的短动画）→ 关闭。
默认：电脑完整，手机轻量，系统开了"减弱动态效果"时关闭；访客选过以后记在本机。

## 图片

- 页面上显示的是 `resized/720/…`（缩略图）和 `resized/1280/…`（大图）里的缩小版，点开大图时看原图；原图保持不动。
- **加了新图片（新活动的海报、封面、相册等）后**，在 `_src` 目录跑一次（需要 Python 和 Pillow）：
  ```
  pip install pillow
  python tools/make-thumbs.py
  ```
  再把生成的 `resized` 文件夹里新出现的图片一起上传。没跑也不会坏：缩小版不存在时网站自动退回原图，只是慢一些。
- 换了同名图片时，config.js 里那张图的地址后面加 / 改 `?v=数字`（缩小版也会跟着刷新），再跑一次上面的命令。

## 修改网站的步骤

1. 改 `_src/` 里的文件。
2. 发布新版本时，把 `_src/index.html` 里所有的 `20260930c` 换成新的日期（开头的 `HJ_VERSION` 一处 + 底部 `?v=` 几处），
   访客就会拿到新文件（离线缓存也会跟着更新）。
3. 生成发布版（需要 Node.js 18+）：
   ```
   cd _src
   npm install esbuild      # 只需第一次
   node build.mjs
   ```
   会覆盖根目录下的 index.html、style.css、sw.js 和各个 .js。
4. 把 `_src/` 和根目录下变了的文件一起上传到 GitHub。

新活动名等标题里出现了新汉字时，可以跑一次 `python tools/make-brush-font.py` 更新毛笔字；
不跑也不影响使用，新字会用 Google 字体或系统字体显示。

万一离线缓存出了问题需要停用：按 `sw.js` 开头注释里的写法，把根目录的 `sw.js` 换成那几行上传即可。
