# 结构与设计取舍

改动前先读一遍，知道每块东西为什么是现在这个样子。具体怎么加功能见 `EXTENDING.md`。

## 总览

```
浏览器 ──GET──▶ GitHub Pages（仓库根目录：index.html、*.js、style.css、assets/…）
   │
   └──POST /api/──▶ Cloudflare Worker（同一域名）──▶ D1（数据）
                                                  └─▶ R2（公告配图，GET /api/image/<key>）
```

- 前端是纯静态页面，没有框架，也没有打包器，只有 `build.mjs` 做压缩。
- 后端只有一个 Worker 文件，在 Cloudflare 控制台里直接粘贴部署，不放进本仓库。

## 前端

### 文件与加载顺序

`index.html` 依次加载：

| 顺序 | 文件 | 职责 |
| --- | --- | --- |
| 1 | `boot.js` | 最先执行，兼容旧浏览器（es2015）。插入样式表、决定动画档位、开屏与回访遮罩，建立 `window.HJ` |
| 2 | `verify.js` | 人机验证组件，提供 `window.HJVerify` |
| 3 | `config.js` | 只放内容和常量，不写逻辑 |
| 4 | `main.js` | 路由、视图、弹窗、时间条、特效、通用工具（`$`、`callWorker`、`escapeHtml`、`createFormGate`…） |
| 5 | `account.js` | 账户与个人数据：网站说明的「致谢」「个人数据」「登录与注册」、登录状态、自动填表、本机提交记录、跨设备同步，提供 `window.HJAccount` |
| 6 | `ticket.js` / `venue.js` / `survey.js` | 各自一个功能，依赖 `main.js` 的工具 |

按需加载的有：`admin.js`（进入 `#internal`）、`huayu.js`（打开花语）、`puzzle.js`（打开花街拼图）、`bard.js`（打开吟游诗人模拟器）、`bard-stage.js`（模拟器里点「来舞台演奏」）、`games.js`（打开小游戏助手）、`assets/lib/exceljs.min.js`（导出 Excel）、`fonts.css`（正文字体，开屏后）。

加载提示（`main.js` 的 `trackLoad(promise, how)`）全站通用，都用开屏的莫古力，按「会不会挡住访客」分两种，网快时什么都看不到：

| 方式 | 样子 | 用在 | 出现 / 最短显示 |
| --- | --- | --- | --- |
| `"block"` | 全屏遮罩 +「正在加载库啵……」，盖住页面防止重复点击；超过 12 秒先收起并提示「网络有点慢」 | 访客点了要等它好才能往下做：提交、打开要读数据的页面、按需脚本、没有缩略图的大图 | 0.35 秒 / 0.7 秒 |
| `"corner"` | 右下角小号转圈，不挡点击 | 在加载但不耽误做别的：进站读站点设置、点赞与点赞数、扩充题库、钢琴采样、拼图 / 问卷状态 | 0.6 秒 / 0.9 秒 |
| `"none"` | 不提示 | 定时刷新、后台再确认开关、预取 | — |

- `callWorker(payload, { load })` 默认 `auto`：访客刚点过 / 按过回车（1.5 秒内）发出的请求，或已有全屏提示在等时接着发出的请求，算 `block`，其余算 `none`。定时器里的刷新包在 `runQuietly(fn)` 里。
- `loadLateScript(file, ready, { load })` 默认 `block`，后台预取传 `corner` 或 `none`。
- 小号转圈的事访客后来真要用到时，对同一个 promise 再 `trackLoad(p, "block")` 升级成全屏。例如站点设置：首次进站时开屏会等它（最多到开屏的等待上限），之后右下角转圈；还没读完就点了要人机验证或花语的功能，`siteStateReady()` 让这次操作全屏等它读完，免得按默认设置走错。
- 全屏出现时右下角的小号转圈先藏起来；开屏或回访遮罩还在时两种都不出现，由它们的莫古力代劳。
- 回访遮罩（不放开屏的进站，含每次更新后第一次打开）：`boot.js` 给 `<html>` 加 `boot-veil`（白天再加 `boot-veil-day`），`index.html` 里的 `#bootVeil`（样式内联，样式表没到也能显示）盖住页面；等样式表、`main.js` 的 `initApp`（白天 / 夜晚、首页卡片）、天空与首页卡片底图、标题字都好了再淡出（主程序就绪后图片与字体最多再等 2.5 秒，整体最长 12 秒；`main.js` 没加载成功时 DOMContentLoaded 后照常撤掉）。莫古力 0.3 秒后才出现，网快时只闪一下底色。入场动画、弹窗公告用 `HJ.boot.afterVeil(fn)` 留到撤掉时；`HJ.boot.veiled()` 查是否还盖着。

### 约定

- 所有脚本都是普通 `<script>`，顶层的 `function` 声明就是全局函数。跨文件调用写成 `window.xxx?.()`，被调用的文件加载失败时也不会连带报错。
- `main.js` 的 `initApp` 与 `admin.js` 末尾的初始化各自包在 `try/catch` 里，一个模块出错不会拖垮整页。
- 页面上的文字统一用 `textContent` 写入。必须拼 HTML 时，所有变量都要经过 `escapeHtml`。
- 路由用 hash（`#latest`、`#previous`、`#ti` …），对照表是 `main.js` 的 `ROUTES`。`/activity/`、`/previous/` 是 `build.mjs` 生成的独立入口：`<html data-page>` 决定显示哪个视图，`<base href="../">` 让相对路径仍然指向站点根目录。
- 弹窗统一登记在 `main.js` 的 `MODALS`，Esc、返回键和 `closeAllModals` 都靠这张表。
- 动画档位挂在 `body` 上：`fx-hover-enabled`（完整）、`fx-lite`（轻量）、`fx-off`（关闭）。纯 CSS 的弹出、晃动动画要在 `body.fx-off` 下关掉。
- 配色：毛笔标题字夜间用 `--lantern-soft`；白天卡片 / 弹窗里的用 `--day-cream`（深绿近黑 #1e2810，也是白天卡片里的深色正文字），直接写在页面背景上的（`.section-title`、卡片外的 `.tab-sec-title`）用 `--day-title`。`--day-gold` 为白天卡片里的加粗小标题与强调字（深暖紫 #4b2341，如网站说明里「点赞」「图片」这一列）。
- 昼夜切换（`main.js` 的 `applyDayNight`）：换配色那一帧给 body 加 `dn-switching` 关掉全页的过渡（两帧后恢复），天空和卡片底图的淡入层先提升图层、隔两帧再开始淡入，只给屏幕内的卡片做淡入，花叶 / 星光淡入结束后再重建。手机上切换时的掉帧由此从每次十几二十帧降到几帧。
- 手机（`pointer: coarse` 或宽度 ≤ 760）首页减负：花叶 8 片（电脑 17 片），明暗用透明度起伏而不是 filter 动画；页头毛玻璃模糊 8px（电脑 17px）。花叶、星光在毛玻璃后面动，模糊半径越大、filter 动画越多，手机上越卡；新增首页毛玻璃或背景动画时留意。
- 小按钮、选项一律用「凸起玻璃」：`style.css` 设计变量里的 `--glass-up`（平常）、`--glass-on`（选中 / 主按钮）、`--glass-sheen`（叠在任意底色上的高光），配 `--glass-up-edge`、`--glass-up-shadow` 等，白天整套自动换。悬停浮起、按下压进去写在「18. 按下反馈」里，新按钮把类名加进那组选择器即可。不要再做没有阴影的扁平按钮。
- 卡片里的输入栏和放文字的框一律用液态玻璃（`style.css` 第 31 节）：输入栏带折射，扁平框是不用 `backdrop-filter` 的「淡玻璃」（原底色 + 光泽 + 整圈同色的 1px 边框 + 均匀内光 + 轻投影）。动画「完整」时再按每个元素的尺寸生成折射滤镜（`main.js`「9b」）。做法、参数、名单和给新框加玻璃的步骤见 `LIQUID-GLASS.md`。变量用 `--lq-`，别和磁贴的 `--lg-` 重名。

### 改动守则（站长定下的，每次改动都要照做）

1. **「角色名@服务器」里的 @ 一律显示成小花。** 凡是界面上显示玩家 id 的地方（新加的列表、卡片、表格、结果页、管理页、canvas 生成的图片），都要经过 `main.js` 的 `idHtml`（HTML）或照购票凭证图那样在 canvas 里画 `worldIcon()`，不要直接把带 @ 的文字塞进去。规则：只换 @ 后面紧跟汉字的（邮箱不动），@ 字透明保留，复制出来仍是 @；样式 `.hj-at`，白天夜晚共用一张图（`main.js` 的 `worldSetup` 把打包在文件末尾的路径数据 `WORLD_PACK` 画成位图，不再发布 `world.svg`，原图和打包工具 `pack-world.mjs` 只留在站长本机）。`config.js` 里写名单时照常写 `角色名@服务器`，渲染时再换。写死在 `index.html` 里的 id 要把整段 `角色名<span class="hj-at">@</span>服务器` 再包进 `<span class="hj-id">`，窄屏换行时整段换，不会断成「阿兹萨🌸梦羽宝」+「境」。
2. **所有界面改动都要兼顾手机和各种宽度。** 至少在 360、390、768、1280 左右几个宽度下看一遍：不出现横向滚动条，文字不溢出、不被截断，按钮手指点得到（不小于约 40px），长 id、长曲名能换行或省略。断点沿用现有的 760 / 640 / 560 / 420（`pointer: coarse` 同样当手机看）；新加样式先找同一块已有的 `@media` 写进去，不要另起一套。弹窗、表格在窄屏下要能滚动或改成竖排。
3. **舞台演奏（`bard-stage.js` 和 `.hjs` 的样式）以流畅、少掉帧为最高优先级**，好看和功能都排在它后面。具体做法：
   - 演奏中每帧只改 `transform` / `opacity`，不改会触发重排的属性（宽高、位置、字体、`innerHTML`），不读布局（`getBoundingClientRect`、`offsetWidth` 等）；要用的尺寸在开局或 resize 时量好缓存。
   - 不在演奏中新增 `filter`、`backdrop-filter`、大面积阴影或模糊；新效果在「简单显示」和自动省电画法（`.is-simple` / `.is-lite`）下必须能关掉。
   - 每帧不新建对象、数组、闭包和 DOM 节点，气泡等元素用对象池复用；不在帧里打日志。
   - 下面的网站被 `hjs-covered` 藏起来不参与绘制，新加挂在 body 上的大块内容要补进那份名单。
   - 改完用结算页的设备诊断（掉帧比例、最长一帧）在手机上实测，掉帧变多就不上线。
4. **新增的按钮、选项、框一律去扁平化，套用现有的玻璃样式，不另起一套。** 按钮用「凸起玻璃」（`--glass-up` / `--glass-on` / `--glass-sheen`，或直接用已有的 `.share-site-btn`、`.acct-device .pill-btn-outline`、`.alarm-seg` 分段控件），并把类名加进「18. 按下反馈」那组选择器；输入栏和放文字的框用液态玻璃（第 31 节，名单与步骤见 `LIQUID-GLASS.md`）；弹窗、小组件用窗口卡片的透光边（`--lg-`）。白天配色跟着整套变量自动换，不在规则里写死颜色。
5. **站长没有指定措辞时，新增的文案以简洁、客观、严肃的语气为主。** 提示、说明、确认框、报错都直接说明是什么、会怎样，不加太多口语化的词（「啦」「哦」「吧」「~」之类），也尽量不用括号补充说明；需要补充的另起一句。站长给了原文的照原文写。

### 安全

- CSP 写在 `index.html` 的 `<meta>` 里。脚本只允许本站，以及 Turnstile 和 Cloudflare 统计；不允许内联脚本。图片只允许本站、`data:` 和 `blob:`。
- `frame-ancestors` 不能写在 `<meta>` 里，要靠 Cloudflare Transform Rule 加响应头，见更新说明。
- 外部来源只有 Turnstile（`challenges.cloudflare.com`）、Cloudflare 统计和 B 站播放器，都在 CSP 里逐个放行。新增外部来源要同时改 CSP。

### 离线缓存（`sw.js`）

- 页面：网络优先，3.5 秒超时后用缓存。
- 带 `?v=` 的脚本和样式：缓存优先。版本号一变就会重新下载。
- 图片和字体：缓存优先，每 6 小时在后台更新一次。

## 后端（Worker）

- **入口**：`GET /ping` 用于自检，`GET /image/<key>` 返回 R2 里的配图，其余请求都是 `POST` JSON `{ action, … }`。
  - 请求必须是 `application/json`。浏览器标为跨站（`Sec-Fetch-Site`）的请求直接拒绝。
  - 请求体最大 256 KB（上传公告配图放宽到图片上限 + 64 KB），边读边数，超了返回 413 `too_large`，不解析（`readLimitedBody`）。
- **处理流程**：`handlers[action]` 分发 → `ensureSchema` → `RATE_LIMITS` 限流 → 执行处理函数。异常统一返回 `server_error`。
- **身份**（详见 README「账户」）：
  - 用账户登录：请求带 `session`（登录令牌，库里只存它的 SHA-256），`authenticate` 按账户的权限认 `a`、`b`、`c`（管理员）、`v`（只读）；普通账户 `u` 没有内部权限。
  - 账户的内部码规则不是「首次填写」时，管理接口还要带 `ticket`（填内部码换来的通行证，绑在这次登录上，按规则过期）。
  - 旧版密码（PASSWORD_A / B / C / VIEW 直接当 `password`）仍然认，管理页「用户管理 → 设置」可以关掉。管理员密码 15 分钟内输错 3 次封锁 15 分钟，内部码输错同样计数。
  - 密码在浏览器里先做 PBKDF2（12 万次）才发出，Worker 再加盐 PBKDF2 一次存下；站长账户 djy998 的密码就是 Worker 密钥 ADMIN_PASSWORD（浏览器那边只做 1 万次，免费版 CPU 不够算 12 万次）。
- **人机验证**：手动验证的题面都不以文字下发：狒科生的职业图标、理科生（仙人微彩）的盘面都是图片（data URL；盘面由 Worker 的 `cactpotImage` 用笔画字形把 1~9 画在 3 × 3 格的正中，只撒几粒淡点，前端 `verify.js` 的 `paintCactpot` 染成深红、铺在九个圆上），文科生的令字由 Worker 画成图片下发（`poemKeyImage`：20 个令字的字模 `POEM_GLYPHS` 用 Noto Serif SC 预先生成、每题随机缩放旋转错位并加淡弧线，前端 `paintImage` 染色；答错的提示不说出令字；出题后 2 秒内交卷按答错算。判卷只认题库：先查 Worker 自带的 `POEM_COMMON` + `POEM_EXTRA`，查不到再查网站的飞花令题库（`games.js` 的 `POEM_SRC` + `games-poems.js`，Worker 从本站取来拼成「|句|句|」缓存 6 小时，另存一份进 Cloudflare 缓存）；整段是某一句里的一截，或几句连着写能从头到尾切成题库里的整句才算，都查不到就判错并提示「请输入更加常见的诗句」）；答案只在加密的题目 id 里（AES-GCM），判卷在服务端。仙人微彩：1、2、3 必在同一条线上（和为 6，报酬 10000 金碟币，唯一最高），八个箭头是选项，答案是线的编号（`r0~r2` 行、`c0~c2` 列、`d0` 左上到右下、`d1` 右上到左下）；答错一次 Worker 作废这题，前端换盘面并提示「请重新作答」。以前的理科生是算术题（`math`，`mathTask` / `mathImage` / `tplMath`）：Worker 已关闭这个接口（`VERIFY_MODES_OFF`）——不出题、不判卷、它发的凭证也不认，防止有人绕过前端用脚本解算术题；代码留着备用。狒科生一次出 3 个职业图标、6 个选项，要把 3 个全部选中才通过（`FF14_PICK` / `FF14_OPTIONS`，6 选 3 共 20 种组合，答案用 | 连起来、顺序不限），选错一次换题；前端选够 3 个自动交卷，图标下面只有一句「点击选中项可取消。」。防「换题攒表」：选项分组固定（`FF14_GROUPS`，3 个图标出自同一组，选项永远是这一组的 6 个名字，换多少次题交集都缩不到 1 个）；每题把图标重新取样一次（`iconVariant`：微小缩放、旋转、错位，颜色不动、不加噪点），字节每题都不一样，脚本没法靠「同一张图」把不同题里的图标对上号；出题后 1.2 秒内交卷按答错算（`FF14_MIN_MS`）。题池轮换（`verifyPool`）：按艾欧泽亚时间把一天分成 4 个时段（每段 6 ET 小时 ≈ 现实 17.5 分钟），每个时段狒科生只出一组（`FF14_GROUPS`）、文科生只出 5 个令字（第 i 个在第 i % 4 组），对应关系每个 ET 日错开一位；理科生没有题库，不分。Worker 先取 `jobicon/s/`（128 px，解码快），没有再取 `jobicon/` 原图。`verifyHumanMode` 返回验证方式并写进记录：`cf`（自动验证，Turnstile）、`ff14`（狒科生）、`poem`（文科生）、`cactpot`（理科生）、`math`（旧版理科生）、`off`（站点关闭了验证）。管理页显示的中文名在 `admin.js` 的 `VERIFY_MODE_NAMES`。
- **IP 属地**：`requestGeo` 从 Cloudflare 的 `request.cf` 取出「国家|地区|城市」。数据库不保存 IP 本身。访客标识（`client_key`）是带密钥的 IP 哈希，只用于限流和防重复。
- **表结构**：
  - `SCHEMA_SQL` 只用 `CREATE … IF NOT EXISTS`。给已有表加列写在 `ADDED_COLUMNS`。
  - 改动后把 `SCHEMA_VERSION` 加 1，新版本收到第一个请求时会自动迁移，不需要手动执行 SQL。

## 设计取舍

| 决定 | 原因 | 代价 |
| --- | --- | --- |
| Worker 挂在同一域名的 `/api/` | 不需要跨域（CORS），CSP 可以只写 `connect-src 'self'` | Worker 的路由必须绑定在本站域名上 |
| 不用内联脚本，启动逻辑放进 `boot.js` | CSP 可以禁掉内联脚本，注入的脚本无法执行 | 多一次请求，由 `<link rel=preload>` 抵消 |
| 字体自托管并按字切片 | 国内访问不依赖 Google；浏览器只下载用到的字 | 仓库多出约 190 个字体文件 |
| 标题字体分两层：`brush.woff2` 只含现有标题用字（开屏预加载），`brush-ext-*.woff2` 按字频切片放约 2700 个常用字（unicode-range 按需下载） | 开屏时就要用，必须很小；新标题多数字不用重新生成 | 标题用到两层都没有的字时才要重新生成 |
| 表结构自动迁移 | 只需在控制台粘贴代码，不需要 wrangler 或 SQL | 只能加表、加列。改列或删列要另写迁移 |
| 只存属地，不存 IP | 管理端够用，也少保管一份个人信息 | 无法按 IP 追查，只能用访客标识的前 6 位对照 |
